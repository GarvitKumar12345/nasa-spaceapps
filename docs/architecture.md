## 2. Conventions (all code)

- **Pixels**: 0-based, integer values at pixel centres; numpy `[iy, ix]` ↔ `(x=ix, y=iy)`. Astropy calls use origin 0. FITS headers keep 1-based CRPIX. Pixel edges: x ∈ [−0.5, nx−0.5].
- **Angles**: RA ∈ [0, 360), Dec ∈ [−90, 90] degrees. Offsets and uncertainties in **mas**. `ra_cosdec`/`pmra` = dRA·cos(Dec). Tangent-plane offsets: east (+RA) and north (+Dec). Display: north up, east left.
- **Time**: recorded times keep value/format/scale (`Epoch`). Models use TDB: `Epoch.mjd_tdb`, Julian years `2000 + (mjd_tdb − 51544.5)/365.25`. Gaia-style catalog epochs are `2016.0 jyear TCB`, converted by astropy, never relabelled UTC.
- **Observer**: `geocenter` with Earth barycentric position from astropy `builtin` ephemeris (ERFA epv00), ICRS-aligned Cartesian, AU. Synthetic truth and fit use the same observer model.
- **Origins** (`DataOrigin`): `observed`, `simulated`, `simulation_truth`, `derived_measurement`, `model_prediction`, `catalog`. Every API object carries one; the UI renders it (see §7.3). Truth is served only by `/truth` and never mixed into measurements.
- **Units**: synthetic images are `electron` per exposure, sky background included (`BackgroundInfo.included_in_image = true`); measurement fits a local constant background — never subtract it twice. Surface-brightness units (future SPHEREx `MJy / sr`) must not be treated as point-source flux: flux becomes `pending` until a validated conversion exists.
- **No NaN in JSON**: contracts reject NaN/inf. Unavailable → `None` + status/reason. NaN is allowed only inside binary pixel planes (no coverage).
- **Determinism**: all randomness from `numpy.random.default_rng(seed)` with child generators per purpose (`np.random.SeedSequence(seed).spawn`). Same seed + same pinned versions ⇒ identical arrays. IDs are deterministic strings (no uuid) except EvidenceRecord.id (browser `crypto.randomUUID()`).
- **Missing data stays missing**: missing/failed observations are listed with status; no frame is fabricated; playback does not interpolate measurements.
- **Measurement inputs**: only native original arrays (image, variance, mask). Registered/reprojected products are `display_only = true` (difference previews, blink).

## 3. Synthetic investigation SYN-NB-01 (exact definition)

`dataset_id = "syn-nb-01"`, title "Training field 01 — nearby-source motion (synthetic)", release `synthetic-v1`, generator `skyshift.synthetic.generator` version `1.0.0`, default seed `20261114`, provider `synthetic`, origin `simulated`.

- **Field**: centre RA 180.000°, Dec +35.000° (ICRS). Stars are simulated; no real source is implied.
- **Common grid** (display/registration output): TAN, centre = field centre, 0.40″/px, shape (176, 176), rotation 0 (north up, east left).
- **Instrument** "SkyShift generic training imager (GTI-1)", kind `generic_synthetic`: 0.40″/px, detector (160, 160), gain 1.0 e⁻/ADU, read noise 5 e⁻, full well 150 000 e⁻. PSF: pixel-integrated circular Gaussian (`includes_pixel_response = true`). Notes must state: toy instrument; not a SPHEREx sensitivity, PSF, or wavelength model.
- **Bands** (`fixed_filter`): `G1` 1.25 µm, width 0.30 µm, FWHM 1.00″, sky 150 e⁻/px/exposure; `G2` 2.15 µm, width 0.40 µm, FWHM 1.40″, sky 260 e⁻/px/exposure.
- **Exposure** 180 s; G2 exposure starts 240 s after the G1 start of the same visit; mid = start + 90 s.
- **Schedule** (visit start, UTC, G1; status per band):

| visit | start (UTC) | G1 | G2 |
|---|---|---|---|
| v01 | 2025-01-08T03:10:00 | available | available |
| v02 | 2025-03-19T22:40:00 | available | available |
| v03 | 2025-05-27T20:05:00 | available | available |
| v04 | 2025-07-10T18:30:00 | missing ("scheduled; no frame delivered (simulated)") | available |
| v05 | 2025-12-16T05:20:00 | available | available |
| v06 | 2026-02-03T01:45:00 | available | missing |
| v07 | 2026-04-22T21:15:00 | available | available |
| v08 | 2026-06-30T19:00:00 | available | available |
| v09 | 2026-12-09T04:35:00 | available | available |
| v10 | 2027-03-02T23:50:00 | failed ("frame failed quality gate: simulated tracking loss") | failed (same) |
| v11 | 2027-05-14T20:25:00 | available | available |

  IDs: observation `syn-nb-01:v01:G1`; frames `syn-nb-01:v01:G1:native`, `syn-nb-01:v01:G1:registered`. Missing/failed observations have no frames. Global registration reference frame: `syn-nb-01:v01:G1:native` (`reference_frame_ids` maps both bands to it).
- **Pointing**: per frame true pointing offset ~ U(−5, 5) px per axis and rotation ~ U(−0.3°, 0.3°) about the field centre (truth WCS). Header ("nominal") WCS = truth WCS perturbed by N(0, 0.6″) per axis and N(0, 0.03°) rotation. Registration must recover the truth WCS from stars; the header error is simulation truth (`FrameTruth`).
- **Sources (truth)**, reference epoch for truth `2026.0 jyear TDB`:
  - 64 stationary background stars (`stationary_star`, zero parallax/pm): positions U over a 78″ × 78″ box about the centre; G1 flux `400 · u^(−1/1.1)` e⁻ capped at 120 000 (u ~ U(0,1)); G2/G1 ratio log-uniform [0.7, 1.6].
  - Close pair: two extra stationary stars 1.10″ apart (PA 60°) at centre + (−18″, −14″), G1 fluxes 6000 and 4000 e⁻ (tests ambiguous association).
  - Candidate `C1` (`moving_nearby_source`): position at 2026.0 TDB = centre + (east +6.0″, north −4.0″); parallax 165 mas; pmra +640 mas/yr; pmdec −1110 mas/yr; radial velocity 0 (declared assumption); flux G1 9000, G2 26 000 e⁻.
  - Variable `V1` (`variable_star`, stationary): centre + (east −12″, north +9″); mean flux G1 15 000, G2 18 000 e⁻; sinusoid, fractional amplitude 0.30, period 23.7 d, phase 0.2 (fraction of period at MJD_TDB 60676.0).
- **Truth positions**: barycentric space motion with astropy `SkyCoord(..., distance=1000/parallax pc, radial_velocity=0).apply_space_motion(new_obstime)` (distant stars: no propagation), then subtract the observer (geocentre) barycentric position → geometric direction → RA/Dec → pixels through the frame's truth WCS. No aberration/light deflection (declared; the synthetic world is geometric).
- **Pixels**: expected = sky + Σ pixel-integrated Gaussians; image = Poisson(expected) + N(0, read_noise²) as float32 electrons. Variance plane estimated from the data: `read_noise² + max(image, 0)` (no truth leakage). 12 fixed hot pixels (same detector positions in all frames): value += U(3000, 8000) e⁻, mask bit 1. Cosmic rays: Poisson(2) per frame, 1–3 pixel streaks, 2000–20 000 e⁻ per pixel, mask bit 2 (flagged as by a pipeline). Pixels above full well are clipped and get bit 4.
- **Mask bits**: 1 `HOT_PIXEL`, 2 `COSMIC_RAY`, 4 `SATURATED`, 8 `NO_COVERAGE` (registered products only).
- **Simulated reference catalog** ("SkyShift simulated reference catalog (Gaia-like format)", release `simcat-v1`, origin `simulated`, reference epoch `2016.0 jyear TCB`): every truth star with G1 flux ≥ 900 e⁻, plus C1 and V1. Values = truth propagated (barycentric, rigorous) to J2016.0 + Gaussian noise. Brightness-dependent errors: σ_pos ∈ [0.05, 1.0] mas, σ_ϖ ∈ [0.06, 1.2] mas, σ_µ ∈ [0.05, 1.2] mas/yr (fainter → larger). Background stars: 5-parameter solutions (true ϖ = µ = 0, so noisy values, including negative parallaxes). C1: 5-parameter, σ_pos 0.3 mas, σ_ϖ 0.4 mas, σ_µ 0.4 mas/yr. V1: 2-parameter solution (no ϖ/µ; `astrometric_params_solved = 3`). Correlations 0 (declared). Radial velocity missing (None) for all.

`tangent.py`: `MAS_PER_RAD`, `wrap_ra_deg`, `sky_to_tangent` (radians; raises ≥ 90°), `tangent_to_sky`, `offsets_mas`, `apply_offsets_mas`, `angular_separation_deg`.
`wcs.py`: `make_tan_wcs(ra, dec, scale_arcsec, shape, rotation_deg=0, crpix0=None)`, `wcs_to_description`, `description_to_wcs`, `pixel_to_sky`, `sky_to_pixel`, `local_jacobian_mas_per_px`, `pixel_scale_arcsec`, `footprint_icrs`, `has_sip`.
`observer.py` (phase 1, science agent): `GEOCENTER_BUILTIN: ObserverModel`; `observer_barycentric_au(mjd_tdb: ndarray, model) -> ndarray (N,3)` ICRS AU; `circular_observer_ecliptic_au(t_yr, phase0_rad) -> (N,3)` (teaching approximation, ecliptic frame); `geocenter_suitability(spacecraft_orbit_radius_km, parallax_mas) -> dict` (max parallax error = parallax · r / 1 AU).

### 4.2 science/astrometry.py (phase 1, science agent)
- `parallax_factors(ra_deg, dec_deg, observer_xyz_au) -> (f_ra, f_dec)`: Δα* = ϖ·f_ra = ϖ(X sinα − Y cosα); Δδ = ϖ·f_dec = ϖ(X cosα sinδ + Y sinα sinδ − Z cosδ).
- `linear_offsets(params, dt_yr, f_ra, f_dec, model) -> (east_mas, north_mas)`.
- `rigorous_offsets(...)` vector propagation (space motion via astropy apply_space_motion, minus observer) — used by tests as the independent reference.
- `fit_astrometry(request: FitRequest, observer: ObserverModel = GEOCENTER_BUILTIN) -> ModelFit`: weighted LSQ on tangent-plane offsets about the weighted-mean position, with full 2×2 measurement covariances; covariance (AᵀWA)⁻¹ (not rescaled by χ²); χ², dof = 2N − p, p-value; identifiability checks with thresholds recorded in `IdentifiabilityReport.thresholds` (dof ≥ 2; baseline ≥ 0.25 yr for pm; for parallax baseline ≥ 0.5 yr, parallax-factor span ≥ 0.5 in at least one axis, normalised condition number ≤ 1e4, |corr(ϖ, other)| ≤ 0.95; weak if cond > 1e3 or |corr| > 0.9); parameters `None` + `not_constrained` when singular/underconstrained; prediction curve (≥ 300 samples spanning the data ± 0.1 yr) with 1σ band and `proper_motion`/`parallax` components; nested-model comparisons (χ², dof, BIC); derived distance only if ϖ > 0 and ϖ/σϖ ≥ 10 (else `not_derived` with reason); total proper motion; `input_hash`; assumptions with numbers (e.g. neglected perspective acceleration bound).
- `fit_input_hash(inputs: FitInputs, measurements: list[SourceMeasurement]) -> str` sha256 over canonical JSON (sorted keys; included measurement id, ra, dec, σs, corr, mjd_tdb, repr floats).

### 4.3 science/catalog.py (phase 1, science agent)
- `propagate_catalog_source(src, epoch, observer, include_parallax=True, pm_allowance_mas_yr=20.0) -> PropagatedPosition`: linear model with full covariance from errors/correlations; 2-parameter solutions are not propagated (position at reference epoch, σ inflated by `pm_allowance · |Δt|`, note). Parallax term only when parallax is present; never invert parallax.
- `padded_search_radius_deg(field_radius_deg, catalog_epoch, observation_epochs, max_pm_arcsec_yr=5.0) -> float`.
- `associate(image_points, catalog_sources, epoch, observer, resolution_arcsec, n_sigma=5.0) -> list[CatalogAssociation]`: radius = max(n_sigma·combined σ, 0.5·resolution); status matched (exactly one candidate and it is mutually nearest), ambiguous (≥ 2 candidates within radius, or blend: candidates closer than resolution to each other), unmatched (note: "no counterpart within radius; not by itself evidence of a new object").

### 4.4 imaging (phase 1, imaging agent)
- `psf.py`: `fwhm_to_sigma`, `gaussian_pixel_integrated(shape, x0, y0, flux, sigma_px)` (erf differences — exact pixel integration), `render_point_sources(shape, xs, ys, fluxes, sigma_px, stamp_radius_px=None)`, `fit_psf(image, variance, mask, x0, y0, sigma_px, fit_radius_px=None) -> PSFFit` (least squares on unmasked pixels, analytic Jacobian, params x, y, flux, background; covariance from (JᵀWJ)⁻¹ with W = 1/variance; χ²_red; flags `MASKED_PIXELS_IN_FIT`, `EDGE_TRUNCATED`, `LOW_SNR`, `NOT_CONVERGED`, `TOO_FEW_PIXELS`; status ok/warning/rejected), `windowed_centroid(...)` (secondary method).
- `detect.py`: `background_stats(image, mask)` (sigma-clipped), `detect_sources(image, variance, mask, sigma_px, threshold=5.0, min_sep_px=2.0, edge_px=3) -> list[Detection]` (matched filter + local maxima, masked pixels ignored, then PSF-refined positions with uncertainties).
- `registration.py`: `SimilarityTransform` (a, b, tx, ty; apply/inverse/params/covariance), `match_by_offset_voting(xy_det, xy_ref, max_shift_px, tol_px)`, `fit_similarity(src, dst, cov_src, cov_dst, clip_sigma=3.0, max_iter=8)`, `RegisteredWCS` (nominal astropy WCS + pixel pre-transform T: `pixel_to_sky(x,y) = nominal.pix2world(T(x,y))`, `sky_to_pixel`, `to_description()` folding T into CD/CRPIX exactly for TAN), `register_frame(detections, nominal_wcs, ref_sky_positions, ref_ids, ...) -> RegistrationResult` (RegistrationSummary contract + RegisteredWCS + per-star residuals + rejected ids).
- `reproject.py`: `reproject_to_grid(image, mask, registered_wcs, out_wcs, out_shape, order=1) -> (image_out float32 with NaN, coverage bool)`; masked input pixels become NaN before interpolation. `difference(a, b)`.

### 4.5 synthetic (phase 1, imaging agent)
- `scenario.py`: dataclasses for the §3 scenario; `default_scenario()`.
- `generator.py`: `generate(scenario, seed) -> DatasetBundle` (Dataset contract with Observations + native FrameProducts (registered FrameProducts are added by the pipeline), arrays, simulated catalog, SimulationTruth). Truth propagation implemented independently with astropy directly (not via science/astrometry.py), so pipeline recovery tests are independent.

### 4.6 pipeline, providers, notebook, API (as implemented)
`pipeline/investigation.py` (`Investigation`, cached by `get_investigation(dataset_id, seed)`):
1. Detect sources in every available native frame (`detect_sources`, PSF-refined).
2. **Register each frame directly to catalog stars propagated to that frame's epoch** (space motion + observer parallax). Only isolated (no catalog neighbour within 2.5 × the widest PSF FWHM), stationary-consistent stars (|µ| < 20 mas/yr and ϖ < 5 mas, or 2-parameter solutions) define the frame solution, so a moving source's catalog values never shape its own registration. Similarity transform, robust (median-scaled) 3σ clipping. Without a catalog, frames are registered to the reference frame's detections and `AstrometricCalibration` flags `ZERO_POINT_UNCALIBRATED`.
3. Reproject each frame to the common grid (bilinear; NaN = no coverage or masked; display-only products `<obs>:registered`).
4. Reference source list = reference-frame detections with S/N ≥ 5, IDs `S001…` by decreasing flux.
5. Tracking: linear prediction in the tangent plane once the links span ≥ 30 days (before that: mean position), radius max(1.5″, 5 × link-residual rms); nearest detection linked unless a second lies within 1.5× its distance (`ambiguous`); `outside_coverage` / `not_detected` / `rejected` (failed registration) otherwise.
6. `measure(source, method)`: one `SourceMeasurement` per observation of both bands (missing/failed → `missing_frame`); PSF fit on native arrays; sky covariance = J Σ_px Jᵀ + registration covariance at that pixel; the common catalog zero-point term is not added per epoch. Quality gates: `LOW_SNR` (S/N < 5) → `pending`; `POOR_PSF_FIT` (χ²/dof > 2, e.g. blends), `EDGE_TRUNCATED`, `MASKED_PIXELS_IN_FIT` → warnings.
7. Change indicators (derived statistics, threshold 5): static-model reduced χ² of positions; largest per-band reduced χ² of fluxes.
8. `associations` (catalog propagated per epoch, resolution = band FWHM), `catalog_overlay`, `difference` (same band, both registered, overlap ≥ 50 %).

`get_investigation` refuses observed datasets. Observed (archive) datasets use `pipeline/observed.py` (`ObservedSession`): dataset + original/display arrays only.

`providers/spherex/` (session 2; details `docs/providers/spherex.md`): `reference.py` (documented facts + sources), `http.py` (bounded IRSA client: IRSA URLs only, ≤ 4 concurrent, retries for 429/502/503/504, byte limits, request log), `discovery.py` (SIA2 URL with explicit collection, VOTable by column name, duplicate-version rule), `screening.py` (byte ranges: IMAGE header + WCS-WAVE of full files), `wavelength.py` (WCS-WAVE via astropy `-TAB` and an independent bilinear evaluator; compatibility groups), `fitsfile.py` (read by EXTNAME, refuse pre-R7/legacy PSF cubes, `validate_spectral_image` → `FileCheck[]`), `fetch.py` (CLI: discover → screen → select → download → manifest), `dataset.py` (manifest + cache → `Dataset`: bands = compatibility groups, native + `archive_wcs_reprojection` display frames, explicit missing/failed statuses, `capabilities` all unavailable), `fields.py` (field presets).

`providers/gaia_dr3/` (session 3; details `docs/providers/gaia_dr3.md`): `reference.py` (documented data-model facts: columns with units/datatypes, J2016.0 TCB, RUWE 1.4, 10.5″/yr bound, acknowledgement), `query.py` (`search_geometry` = footprint + proper-motion margin + neighbour margin; explicit ADQL; TAP form with MAXREC), `catalog.py` (VOTable by column name → `GaiaCatalog` with **string** source_ids; `schema_checks`; every QUERY_STATUS INFO inspected for OVERFLOW), `rows.py` (row → `CatalogSource`), `fetch.py` (CLI: footprints from the SPHEREx cache, COUNT, field query, archive ESDC_EPOCH_PROP check, overflow probe, manifest), `paths.py`. The bounded HTTP client (`providers/spherex/http.py`) takes a host allow-list and form POSTs.

`science/epoch_propagation.py`: vectorised rigorous uniform-space-motion propagation (Gaia DR3 doc §4.1.7) with 6×6 covariance (Michalik et al. 2014 μ_r terms), explicit handling of missing motion / RV / weak parallax, and `predict_observed` = propagation + one observer-parallax term (no aberration, no light deflection). `imaging/epsf.py`: SPHEREx ePSF library (zones from the file's EPSF table, A&K normalisation, bicubic spline) and `fit_position` (LM, plane background, VARIANCE weights, flags excluded). `science/alignment.py`: reference selection with recorded reasons, residual statistics, held-out translation test, injection-recovery (global and near saturated regions), aberration convention test. `pipeline/observed_gaia.py` (`ObservedGaia`): per-frame predictions, overlay, source detail and the field `AlignmentReport`, disk-cached in `backend/cache/alignment/` under a hash of all inputs and the code.

`science/alignment.py` (session 3, revised in session 4):
- reference selection and the ePSF fits;
- residual statistics with the Paule–Mandel extra scatter;
- `shared_systematics`: PSF mismatch from adjacent-zone refits, and the centroid convention from the frame's ePSFs (windowed / barycentre centroids), with missing terms named;
- `evaluate_translation`: random ⊕ shared σ, the shared part not shrinking with N, plus a held-out test;
- the convention test.

`science/estimator_stress.py` (session 4): an independent renderer (analytic PSFs integrated over each pixel), A&K ePSFs built from them, and the controlled variation matrix used by `tests/test_estimator_stress.py` and `scripts/estimator_review.py`.

`notebook/evidence.py`: `validate_record` (schema, label vs origin, ids, truth only for simulated, fit freshness by recomputing `fit_input_hash`), `reproduce_record` (regenerate from seed, re-measure, re-fit; tolerances 1e-9 deg, 1e-6 relative flux, 1e-6 parameter units), `record_to_csv`.

## 6. Binary pixel planes
`GET .../pixels` returns raw little-endian bytes: `float32` for image/variance (registered products: NaN = no coverage or masked), `uint16` for synthetic masks and `uint32` for SPHEREx flags (bits from the file's FLAGS header; display products add bit 31 `SKYSHIFT_NO_COVERAGE`). Headers: `X-SkyShift-Shape: ny,nx`, `X-SkyShift-Dtype: float32|uint16|uint32`, `X-SkyShift-Unit`, `X-SkyShift-Origin`, `X-SkyShift-Frame`, `X-SkyShift-Plane`, `X-SkyShift-Display-Only: true|false`. Row-major, row 0 = y 0 (bottom of the displayed image when north is up: the viewer flips vertically so +y is up).

## 7. Frontend

### 7.1 Stores (zustand; one file each)
- `state/app.ts` (foundation): `section` ('observatory'|'motion'|'evidence'|'methods') synced to `location.hash` (`#/observatory`), API health, toasts/live-region messages.

## 8. Validation
pytest markers = categories (`math`, `coords`, `measurement`, `registration`, `catalog`, `pipeline`, `contracts`, `api`, `archive`, `slow`, `live`); `archive` = recorded real SPHEREx and Gaia DR3 products checked offline; `registration` includes the SPHEREx alignment diagnostics, `catalog` the Gaia propagation checks against the archive's own ESDC_EPOCH_PROP results, `measurement` the ePSF checks. A live test records non-failure observations with `record_property("note", …)` → `TestResult.notes`. `live` tests are deselected by default; their absence/skip is reported as "not run". `scripts/validate.py` runs pytest (JSON via conftest hook), vitest (`--reporter=json`), Playwright (`--reporter=json`), and merges to `validation/report.json` with UTC timestamp, environment and a source hash. Methods renders that file via `/api/validation`; with no file it shows "not run". Tolerances must be justified from noise models (e.g. 3σ of the reported uncertainty, or Monte-Carlo pull widths), not tuned to pass.

## 9. Provider status (session 3)

## Stage 3 additions

`validation/vanmaanen2_motion_stage2.json` and its original CSV/figures remain immutable research artifacts. `pipeline/target_motion.py` serves a read-only view; no fit runs on an HTTP request. `validation/study_seal.py` checks a manifest generated from the Git archive of `0c7f4ab` by `scripts/seal_recorded_study.py`. It seals the static scientific import closure, parent package initializers, dependency versions, selected shared type declarations/imports, recorded Gaia/SPHEREx/calibration data, stage-1/first-pass inputs, and Stage 2 outputs. Text hashes normalize CRLF to LF; binary hashes remain exact. Metadata-only modules are excluded with reasons. The legacy execution source hash is retained and differs from the committed reference hash; this is explicitly not proof of historical execution. A missing/invalid seal is unavailable; changed relevant files are changed. Missing cached cutouts are separately reported; changed present cutouts fail integrity. Whole-application test freshness remains a separate global hash, including the new data and seal files.

`GET /api/datasets/{dataset_id}/target-motion/evidence.zip` packages recorded evidence, exact original study/CSV, figures, recorded provider provenance, seal, current integrity status and reproduction instructions. Cutouts are not bundled. It is independent of the browser-local synthetic Evidence Notebook schema. Figure URLs use an allowlist pattern under `/api/studies/vanmaanen2/figures/`.

`#/blinkir` mounts an isolated React module. Its API router is `/api/blinkir`: `presets`, `simulation/{target}`, `export`, and an explicitly unavailable `observations` endpoint. The generator is adapted from audited source in `reference/blinkir`, with a stable SHA-256 preset seed. Images have simulated origins, model spectra have model-prediction origins, and values use arbitrary units. The plot shows 102 illustrative samples, not observed channels. Pixel intensity inspection is not spectral extraction. Detector selection supplies wavelength context only. No standalone app, live epoch fabrication, synthetic fallback or purported mJy calibration is imported. Requests are aborted and playback stops when leaving the section; all five established navigation items coexist in the same router.
