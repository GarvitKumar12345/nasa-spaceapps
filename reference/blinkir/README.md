# BlinkIR reference — audited, not a running application

Selected source from the user-supplied `skyshift hackathon.zip`; provenance and archive checksum are in SOURCE.json. Bundled virtual environments, dependencies, caches and credentials were excluded. These historical files are preserved for comparison and are **not imported or served**.

The reference generator creates Gaussian star scenes and illustrative spectral curves. Its label `CALIBRATED_BENCHMARK_CACHE`, fabricated epoch shifts via `np.roll`, interpolated “102-channel” live curves, median pixels called mJy, centre-distance spectrum selection, preset-derived “measured” motion, and automatic synthetic fallback are unsupported. Reference target flags/exposure counts and “official” labels are unverified claims, not accepted evidence.

The native module ports only the educational generator, with a stable SHA-256 seed. It labels images simulated, wavelengths illustrative model samples, and values arbitrary units; supplies no observed dates, measured motion, calibrated flux or archive quality flags. Pixel inspection is distinct from the preset model spectrum. Its export is a simulation lesson, separate from the Evidence Notebook. Live extraction answers unavailable; existing observed SkyShift services are unchanged.
